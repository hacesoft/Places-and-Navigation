# Navigace: mobilní rozložení

Verze: 1.0.0. Aplikace používá Layout API Shared App Core na Nextcloudu 35.

Core určuje dostupnou výšku a režim postranního panelu podle šířky aplikace. Na úzké obrazovce se seznam otevírá nad mapou a má vlastní posuv. Mapa zpracovává dotykové posouvání a zoom; seznam, vyhledávání a nastavení používají běžný posuv prohlížeče.

## Kontrola na telefonu

Vyzkoušejte mapu, postranní seznam, hledání, sdílení a nastavení. V úzkém okně na desktopu ověřte, že panel a tlačítko menu přepínají do stejného režimu.
