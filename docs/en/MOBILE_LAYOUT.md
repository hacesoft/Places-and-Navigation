# Places & Navigation: mobile layout

Version: 1.0.0. The app uses the Shared App Core Layout API on Nextcloud 35.

Core determines the available height and sidebar mode from the application width. On a narrow screen the list opens over the map and scrolls independently. The map handles touch panning and zoom; lists, search and settings use browser scrolling.

## Check on a phone

Test the map, sidebar, search, sharing and settings. In a narrow desktop pane, verify that the drawer and menu button switch to the same mode.
