# Changelog

## 1.0.0 — 2026-10-20

First public source release for Nextcloud 35.

### Features
- Nested map lists, favorites and place search
- Location, geocoding and user/group sharing
- Navigation handoff to external providers

### Compatibility
- Nextcloud 35.
- Requires Hacesoft Shared App Core 0.18.8 or newer.
